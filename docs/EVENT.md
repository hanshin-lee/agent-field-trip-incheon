# Agent Field Trip 2026: Incheon

GDG Incheon · Google I/O Extended
**2026.09.12 (토) 10:00 – 16:00**

- **베이스캠프:** 인천맥주 호랑이 (인천상상플랫폼)
- **주 활동장소:** 동인천 관광지 일대
- **진행 방식:** 사전 구성된 팀 단위 · 현장형 Agent 해커톤
- **Powered by:** Runyour Agent (몬드리안에이아이)

## 미션

> 인천의 현장에서 발견한 장소 경험 하나를 Agent와 함께 작동하는 서비스로 만들어주세요.

완벽한 서비스를 만드는 것이 목표가 아니다. 무엇을 발견했는지, Agent에게 어떻게
일을 맡겼는지, 그 흐름이 실제로 작동하는지를 본다.

## 완주 요건 — 세 가지 전부 필요

1. 현장에서 남긴 사진이나 메모 **1개** → `evidence/field-notes/`
2. 그 발견이 반영된 작동하는 핵심 서비스 **1개** → 배포 URL 또는 녹화
3. Agent에게 맡긴 역할 → `HANDOFF.md`에 기록

> 배포에 실패해도 괜찮다. 저장소 · 화면 녹화 · 캡처로 작업을 확인하면 완주로 인정된다.
> 그래서 `evidence/`가 있다. 배포가 막히면 녹화부터 남겨라.

## 운영 방식

- 현장에서는 **모바일로 Agent를 원격 구동**한다. 노트북은 복귀 후 검증과 발표 준비용.
- 팀은 행사 전에 구성한다. 당일 팀 빌딩은 없다.
- 동인천 일대 **도보 이동** 포함. 편한 복장.
- AI API 토큰(Gemini · ChatGPT · Claude)은 참가자 전원에게 지급된다. 개인 결제 불필요.

**Agent에게 어떻게 일을 맡겼는지**를 본다.
